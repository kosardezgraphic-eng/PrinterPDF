# Text overlays

Open **Insert** to access the text panel. Add multiple texts and select them by tab or by clicking a text in the sheet preview; double-click a text to open the panel and focus its editor. Drag in move mode; Ctrl/Cmd-drag shows a copy and commits a new independent text on release. Cancel a drag with Escape or pointer cancellation. Text edits, creation, movement, copying and deletion use the workspace undo history and are saved in project JSON.

A text can target an output sheet or the visible box of a document page, with percentage coordinates relative to that target. A page-targeted text is drawn for each matching occurrence in an imposed layout, using the page's displayed crop box and occurrence transform; clipping follows the cell. Current and selected scopes capture the current sheet/page or checked page IDs at the moment of applying the scope. Even/odd/first/last page scope uses the original workspace page order, including unchecked pages; sheet scope uses output-side order. All occurrences of one text share its settings. For a sheet-targeted selected scope, a sheet matches when it contains at least one captured checked page. Current sheet scope uses the side index, which may refer to a different side if pagination changes later.

Vazirmatn, Shabnam and Sahel are bundled under their Open Font Licenses for offline use. Titr, Mitra, Nastaliq, Tahoma, Arial and Times New Roman are offered as local system fonts; if missing, the browser uses a fallback. Text and optional background colors accept CSS color strings, including hex and RGBA. Text is clipped to its percentage-sized box and long single lines are fitted into its width. Preview and PDF use the same Canvas text renderer; PDF text overlays are raster images at up to 200 dpi (not searchable/vector text) with a 4096-pixel per-side cap. Output can differ between operating systems when relying on fonts that are not bundled.

Page numbering is now disabled for new workspaces. Existing project settings are preserved. The existing numbering feature can be enabled on the Insert tab; it is distinct from text overlays. The legacy numbering and watermark output still have existing preview/PDF differences (including Persian numbering output). Direct and batch printing are not connected to actual document submission.

Unit tests exercise text scopes, interactions, history, project restoration and PDF image resource placement. A simple generated PDF was checked with an independent PDF renderer for placement and background pixels. Actual Persian font appearance, zoom interactions, browser/Electron touch behavior, printer output, 60 fps and 10,000-page performance remain unverified.

Font license texts are distributed in `public/licenses/` and included in production builds.

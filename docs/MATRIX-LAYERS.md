# Matrix content and layer editing

The default **Select / move / resize** tool selects an image when it is clicked or tapped; its handles then appear, and it can be dragged anywhere on the current sheet. Clicking elsewhere hides the handles without clearing the sidebar's multi-selection. Corner handles preserve the current aspect ratio about the opposite corner; edge handles resize only one axis. Edited content can extend beyond its original cell, but it is clipped at the physical sheet edge. Preflight warns if content extends beyond that edge. Unedited fill-mode cells retain their existing cell clipping.

The default **This cell** scope edits only that occurrence, including a single step-and-repeat copy. **Selected thumbnails** and **All pages** remain batch operations; they replace per-cell transforms for the targeted pages. A right-click on the content, or holding a finger on it for about 600 ms, opens layer commands for front/back and single-step ordering. The same order is used in PDF export. Geometry and layer commands can be undone and redone. A moved object's thumbnail shows its position on the sheet; for repeat copies it follows the last interacted copy.

Per-cell settings are stored in the layout and project JSON. Sequential keys follow the source page ID; repeat keys also include grid row and column. Changes to the repeat matrix can make old positions temporarily inaccessible until that position exists again. Source bytes are still omitted by the existing project save mechanism; reopening a project does not restore originals for PDF export.

Cropping remains page-level, including all repeat copies; a crop resets individual transforms for the affected pages. Reset on a cell removes its transform and that page's shared crop. Text/shapes remain outside this feature. Preview uses existing raster thumbnails; tests cover PDF overlap, clipping and opaque PDF page backgrounds, but do not establish full WYSIWYG for effects, transparency or all formats. Automated pointer tests are simulated in jsdom, not a real touchscreen/browser, and large-document performance is not verified.

## Navigation and sheet guides

Clicking a thumbnail brings its first occurrence into the main preview and scrolls the preview viewport to it; Ctrl/Shift thumbnail selection and the independent print checkboxes retain their usual meaning. When a page is excluded from printing, its thumbnail opens a labelled, temporary **read-only** sheet instead. The print range, exported output and preflight remain based on the actual print selection. Use the return button or click a printable thumbnail to return to real sheets.

Matrix size is entered using rows and columns (1–10), without presets or a grid picker. In the default combined tool, click an image or the paper to reveal margin (green) and uniform row/column gutter (purple) guides for that sheet; click outside to hide them. Image resize handles still require clicking the image. Gutter changes apply uniformly along the corresponding axis. The layout tool also requires clicking a sheet first. These edits change the global layout, not just that sheet; the guides appear only on the clicked sheet. Preview-only sheets cannot be edited. Some controls and tabs use icons with localized tooltips and accessible names.

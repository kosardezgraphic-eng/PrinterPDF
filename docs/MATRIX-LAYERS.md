# Matrix content and layer editing

With **Move / resize** selected, choose the page via its thumbnail and drag its content anywhere on the current sheet. Corner handles preserve the current aspect ratio about the opposite corner; edge handles resize only one axis. Edited content can extend beyond its original cell, but it is clipped at the physical sheet edge. Preflight warns if content extends beyond that edge. Unedited fill-mode cells retain their existing cell clipping.

The default **This cell** scope edits only that occurrence, including a single step-and-repeat copy. **Selected thumbnails** and **All pages** remain batch operations; they replace per-cell transforms for the targeted pages. A right-click on the content, or the ⋮ button next to its handles, opens layer commands for front/back and single-step ordering. The same order is used in PDF export. Geometry and layer commands can be undone and redone. A moved object's thumbnail shows its position on the sheet; for repeat copies it follows the last interacted copy.

Per-cell settings are stored in the layout and project JSON. Sequential keys follow the source page ID; repeat keys also include grid row and column. Changes to the repeat matrix can make old positions temporarily inaccessible until that position exists again. Source bytes are still omitted by the existing project save mechanism; reopening a project does not restore originals for PDF export.

Cropping remains page-level, including all repeat copies; a crop resets individual transforms for the affected pages. Reset on a cell removes its transform and that page's shared crop. Text/shapes remain outside this feature. Preview uses existing raster thumbnails; tests cover PDF overlap, clipping and opaque PDF page backgrounds, but do not establish full WYSIWYG for effects, transparency or all formats. Automated pointer tests are simulated in jsdom, not a real touchscreen/browser, and large-document performance is not verified.
